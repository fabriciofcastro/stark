#### 1. **ThemeProvider**
```typescript
interface ThemeConfig {
  name: string;
  primary: string;
  accent: string;
  particles: string;
  icons: string[];
  animations: AnimationConfig[];
  background: BackgroundConfig;
}

const themes: Record<string, ThemeConfig> = {
  support: { /* configuração suporte */ },
  cloud: { /* configuração nuvem */ },
  // ... outros temas
};
```

#### 2. **AnimatedBackground**
```typescript
interface AnimatedBackgroundProps {
  theme: ThemeConfig;
  variant: 'hero' | 'section' | 'page';
  intensity: 'low' | 'medium' | 'high';
}
```

#### 3. **ThemedSection**
```typescript
interface ThemedSectionProps {
  theme: string;
  children: React.ReactNode;
  variant: 'hero' | 'content' | 'footer';
  className?: string;
}
```

#### 4. **ParticleSystem**
```typescript
interface ParticleSystemProps {
  theme: ThemeConfig;
  count: number;
  speed: number;
  size: 'small' | 'medium' | 'large';
}
```

## 🎨 SISTEMA DE DESIGN CONSISTENTE

### 🎯 **PRINCÍPIOS DE DESIGN**
1. **Consistência Visual** - Cada página tem identidade única mas mantém consistência
2. **Hierarquia Clara** - Cores e animações guiam o olhar do usuário
3. **Performance** - Animações otimizadas para todos os dispositivos
4. **Acessibilidade** - Suporte a preferências de movimento reduzido
5. **Responsividade** - Design adaptativo para todos os tamanhos de tela

### 🎨 **ELEMENTOS VISUAIS COMUNS**
- **Gradientes dinâmicos** - Mudam conforme o tema
- **Partículas animadas** - Específicas para cada área
- **Ícones temáticos** - Emojis e símbolos relevantes
- **Transições suaves** - Entre seções e páginas
- **Efeitos de hover** - Interatividade em todos os elementos
- **Loading states** - Animações de carregamento temáticas

### 📱 **RESPONSIVIDADE**
- **Mobile First** - Design otimizado para dispositivos móveis
- **Tablet Friendly** - Layout adaptado para tablets
- **Desktop Enhanced** - Efeitos extras em telas grandes
- **Performance** - Animações reduzidas em dispositivos lentos
